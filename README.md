# FE 完全学習 — 基本情報技術者試験 学習Webアプリ

基本情報技術者試験（FE）の出題範囲（IPA シラバス Ver.9.2・試験要綱 Ver.5.6）を、問題演習を中心に学べる無料の Web アプリです。ログイン・インストール不要で、一度読み込めばオフラインでも使えます。学習データは端末内（IndexedDB）にだけ保存され、外部に送信されません。

> 本アプリは IPA（独立行政法人情報処理推進機構）とは関係のない非公式の学習教材です。試験制度・出題範囲は必ず IPA の公式情報で確認してください。

**公開URL：** https://minkohno-hub.github.io/Fundamental-Information-Technology-Engineer-Examination/

## 主な機能

- 一問一答（5/10/20/50問、分野・ランダム・未回答・苦手・復習・お気に入り・理解度別）と、未回答・要復習・復習時期を組み合わせる標準出題
- 科目B 短時間学習（短いプログラムのトレース、入力式解答）と、計算・プログラム専用の本格モード
- 擬似言語（IPA 別紙2準拠）の実行シミュレーター（1行ずつ進む／戻る、変数・配列・条件・繰返し回数・実行履歴）
- 模擬試験（科目A 60問90分／科目B 20問100分、本番・練習・短縮・時間無制限、見直しフラグ、試験後の分析と復習セット）
- 学習分析（初見正答率・全体正答率・復習時正答率、分野別、苦手分野、連続学習日数、シラバス網羅率）
- IT用語辞典（略語の英語正式名称・日本語訳・単語ごとの意味）、コンパクト参考書、プログラミング講座、全文検索
- 理解度・お気に入り・メモ、文字サイズ・ダークモード・動きの抑制、学習データのエクスポート／インポート
- 問題の不備報告（端末内保存と GitHub Issue 用テキストのコピー）

## 開発

```bash
npm ci
npm run dev            # 教材データをビルドして開発サーバーを起動
npm run build          # 教材検証 + 型検査 + 本番ビルド（dist/）
npm test               # 単体テスト（Vitest）
npm run test:e2e       # E2E テスト（Playwright、要 npx vite build）
npm run check:release  # 公開条件（1,000問以上・網羅率など）の確認
```

教材は `content/` の YAML で作成します。書き方は [docs/CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md) を参照してください。仕様・設計・進捗は `docs/` にあります。

## 公開

`main` または開発ブランチへの push で GitHub Actions が教材検証・型検査・テストを行い、GitHub Pages にデプロイします（リポジトリの Settings → Pages で Source を「GitHub Actions」にする必要があります）。
