# プロジェクト仕様

## 目的

基本情報技術者試験（FE）の全出題範囲を、無料・ログイン不要・インストール不要・オフライン対応の Web アプリで、問題演習を中心に学べるようにする。

## 前提とした公式情報（2026-10-20 確認）

| 項目 | 内容 | 出典 |
| --- | --- | --- |
| 科目A | 90分・60問（四肢択一）、うち評価は56問 | IPA 試験要綱 Ver.5.6（2026-07-06） |
| 科目B | 100分・20問（アルゴリズムとプログラミング16問、情報セキュリティ4問）、評価は19問 | 同上 |
| 採点 | IRT（項目応答理論）、各科目 1000点満点中 600点以上で合格 | 同上 |
| シラバス | 基本情報技術者試験（レベル2）シラバス Ver.9.2（2026-01-08）、23 中分類 | IPA |
| 擬似言語 | 「試験で使用する情報技術に関する用語・プログラム言語など」Ver.5.1 別紙2 | IPA |
| 公開問題 | 令和5〜8年度の CBT 公開問題（科目A 20問・科目B 6問／年）。教育目的の利用可、出典明記と改変の明示が条件 | IPA FAQ |
| 今後 | 2027年度春頃からの新制度に向けたシラバス案 Ver.0.1（2026-09-30）。範囲・時間・問題数は現行と同じと説明されている | IPA |

制度変更は確定情報ではないため、本アプリは現行の Ver.9.2 に準拠し、変更が確定したらシラバス JSON を差し替える。

## 必須要件（緩和しない）

1. シラバス Ver.9.2 の全中分類・末端論点を網羅し、網羅状況を機械的に計測・表示する
2. 品質承認済み（verified）問題 1,000 問以上。科目A・科目B の両方。重複問題なし
3. 各問題：正解の理由、各選択肢の正誤理由、基礎知識、関連知識、略語の正式名称・日本語訳・単語分解
4. 各問題に出典・ライセンス状態・検証状態（draft/checking/verified/rejected）と検証ログ
5. 学習モード：一問一答、標準出題、科目B 短時間学習（入力式可）、計算・プログラム専用モード、擬似言語シミュレーター
6. 模擬試験：科目A 60問90分／科目B 20問100分、本番・練習・短縮・時間無制限、見直しフラグ、履歴、分析、復習セット。合格可能性・IRT 得点の推定は表示しない
7. 学習分析：初見・全体・復習時の正答率、分野別、苦手分野、連続日数、網羅率、推移
8. 用語辞典・コンパクト参考書・プログラミング講座・検索
9. スマホ/PC 対応 UI、文字サイズ、ライト/ダーク、動きの抑制、選択肢の一時非表示、中断・再開、お気に入り・メモ・理解度
10. 端末内保存、エクスポート/インポート（検証・上書き確認）、オフライン準備状況の表示
11. GitHub Pages 自動デプロイと公開 URL での動作確認
12. 問題報告（端末内保存・Issue 用テキスト）
13. セキュリティ：秘密情報なし、安全なレンダリング（HTML を直接挿入しない）、インポート検証、依存関係監査、CSP
14. 自動テスト（データ・学習・模試・保存・UI・オフライン）と公開条件チェック（`npm run check:release`）

## 対象外

- ログイン、サーバー側への学習データ保存、合格可能性の予測、旧午前試験の過去問の転載
