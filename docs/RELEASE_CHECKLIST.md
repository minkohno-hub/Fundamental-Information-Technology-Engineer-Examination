# 公開チェックリスト

自動判定できる項目は `npm run check:release`（`tools/check-release.ts`）で確認する。手動項目は公開 URL で確認して記録する。

## 自動判定

- [ ] verified 問題 1,000 問以上、ビルドエラー 0、レビュー待ち 0、ほぼ同一の問題 0
- [ ] 科目A 600問以上・23中分類すべて、シラバス末端論点の 80% 以上
- [ ] 科目B 本番形式アルゴリズム 80問以上、セキュリティ 20問以上、一問一答 50問以上
- [ ] シミュレーター付き 50問以上、用語 500語以上、参考書 10章以上、講座 8回以上
- [ ] docs 一式・README・LICENSE

## テスト

- [ ] `npm run typecheck`、`npm test`（単体・教材データ）
- [ ] `npx vite build && npm run test:e2e`（スマホ幅・PC幅、オフライン）
- [ ] `npm audit` で脆弱性 0

## 公開環境（手動）

- [ ] GitHub Pages の URL でホームが表示される
- [ ] 一問一答・模擬試験・辞典・シミュレーター・設定（エクスポート/インポート）が動く
- [ ] 一度読み込んだ後、機内モードで再読み込みしても演習できる
- [ ] スマホ実機（または幅 390px）で横スクロールが出ない
