## 発見して修正した不具合（抜粋）

- 模擬試験を終えた後の画面離脱で、終了済みの試験が上書きされる → 保存前に状態を再読込して終了済みは更新しない
- 選択肢シャッフル後に解説の記号が合わない → 解説から記号を除去し、記号参照をビルドで禁止
- 連結リスト問題のシミュレーターが実行時エラー → クラス定義などの実行オプションをシミュレーターに渡す
- 用語の別名に別の概念が登録されていた（例：静的解析がファジングの別名）→ 独立した用語として定義し直し（全辞典の監査を実施中）
- 講座の動作例が関数本体に吸収され何も出力しない → 出力がない例をビルドエラーに
- Firefox で画面が真っ白のまま起動しない（永続ストレージの要求 `navigator.storage.persist()` が許可ダイアログの応答まで解決せず、描画が待たされていた）→ 待たずに描画
- 保存データの一部が壊れていると起動に失敗しうる → 読み込み時に各記録を検証し、不正なものだけ無視（削除はしない）して設定画面に件数を表示。教材更新で消えた問題を参照する中断データ・模擬試験は整合させ、画面にメッセージと戻る導線を表示
- メモが 5000 文字を超えると無言で切り捨てられる → 入力中と保存時にメッセージを表示。保存失敗（容量不足など）は画面上部に通知

## 既知の制約・未検証事項

- ブラウザ：E2E は Chromium（スマホ幅 Pixel 7・PC 幅）、Firefox、WebKit（Playwright 同梱の Desktop Safari）で実行。実機の iOS Safari・Android Chrome・Firefox は未検証。WebKit では Playwright が `setOffline` + 再読み込みに対応しないためオフライン起動テストを省略（Chromium・Firefox では実施）。クリップボード権限の付与は Chromium のみのため、コピー操作の検証も Chromium のみ。アクセシビリティ（axe）とキーボード操作のテストは Chromium の PC 幅のみ
- 知識問題（機械検証の対象外）は作成時の逐問レビューのみで、第三者の専門家による監修は受けていない。特に法務・規格（JIS Q 20000、システム監査基準、個人情報保護法など）は改正が多く、原典との照合が今後の課題
- 擬似言語インタプリタは IPA 別紙2のうち出題に必要な範囲を実装。`÷` は実数除算（整数型変数への代入で切捨て）、文字列の添字アクセスは未対応、関数定義の後に書いたトップレベル文は関数本体に含まれる。IPA 公開問題で使われる記法（繰返し処理の終了、商・余り、平方根、文字列・配列の操作など）は追加実装済み
- IPA 公開問題：科目A 74 問・科目B 24 問を出典・改変の明記付きで公開。図の再現が必要な 6 問は除外
- 法務・規格の事実確認は一部のみ一次情報と照合済み（docs/FACTCHECK_LOG.md）
