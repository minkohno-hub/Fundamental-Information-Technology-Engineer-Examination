## 照合の方法と限界（正直な記録）

- 区分の凡例: **[本文]** 公式サイトのページ・PDF を取得して本文を読んだ／**[転載]** 公的機関または準公的機関が掲載する条文の転載（著作権情報センター CRIC、Wikibooks、gdpr-info.eu）を読んだ／**[抜粋]** 検索結果に表示された公式サイトの抜粋で確認（本文は読んでいない）／**[未了]** 確認できていない。
- e-Gov 法令検索（laws.e-gov.go.jp）と日本法令外国語訳DB は、確認時「システムメンテナンス中」の画面（HTTP 403）を返し、条文を直接参照できなかった。経済産業省・特許庁・法務省・公正取引委員会のサイトは取得時に HTTP 403 を返した（WebFetch・curl のどちらも）。このため、これらの機関の文書は検索結果の抜粋でのみ確認した項目がある（下表に明記）。
- 刑法・民法の条文は Wikibooks の転載で読んだ。公式条文との一字一句の照合は未了。
- 有償規格（JIS Q 20000-1、JIS Q 27001/27002 の本文）は、JIPDEC「ITSMS ユーザーズガイド（JIS Q 20000-1:2020 対応）」中の規格引用と、JSA 公開の JIS Q 27002:2024 プレビュー（目次）で確認した。規格本文そのものの全文は読んでいない。
- システム監査基準（令和5年版）の経済産業省 PDF は取得できず、基準本文を引用している解説ページ（kogures.com、Qiita）で確認した（二次情報）。
- 数値計算の問題（A15・A18・A21・A22 の計算）は、Pass 2 までの検算式による確認のみで、今回は新たな一次情報の照合対象外。

## 用語辞典の略語確認

- 略語展開（fullName）が登録された約 450 項目を全件目視で確認し、IPA シラバス Ver.9.2 の「略語(英語名:日本語名)」139 組と機械照合した（照合できた 88 項目）。シラバスと食い違ったのは RAT（上記で修正）、PMO（シラバスは Program Management Office、辞典は Project Management Office。PMBOK 系の用語として許容、変更なし）、CSF（複数形の違いのみ）、bps（bit/bits のみ）、ANSI（シラバス側の誤記 America）。EOQ は IPA シラバスが Economic Ordering Quantity と表記しており、辞典もそれに合わせている。
- 別名の誤登録を検出（IEC→ITU、CPO→CEO）。別名の全体の検証を機械的には実施していない。
- セキュリティ・ネットワーク・法務の略語（IDS・IPS・WAF・DMZ・TLS・WPA3・CSIRT・SIEM・PCI DSS・CVSS・GDPR・PL法 ほか約 150 項目）は、RFC・規格・公式サイトでの表記と記憶の整合を確認した。ネットワーク系の RFC 題名の逐語確認は未実施。
