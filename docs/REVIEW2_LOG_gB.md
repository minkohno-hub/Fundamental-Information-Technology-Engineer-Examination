## 修正せず記録するもの（不確実・方針事項）

- B/drill.yaml の B-DRL-029 と alg-core の B-ALG-030, B-ALG-033 は、`length()` / `substring()` を使い、`substring(s, n － 2, 3)` や `substring(s, 0, 1)`（0 文字目は空文字列）のように IPA 別紙2 の `sのi文字目の文字` で置き換えられない用法を含むため、問題文で関数の定義を明記したまま残した。drill の他の問題は今回の修正で全て `sの文字数` 形式になった。
- 「配列の末尾に x を追加する」（`bits の末尾に n mod 2 を追加する` など）は、IPA 別紙2 に同じ記述があるかを一次資料で確認できていない。インタプリタは対応しており、問題文では意味が自明なため残した。
- sec.yaml の事実・助言（PPAP、パスワード定期変更の見直し、マルウェア感染時の電源非遮断、アンチパスバック、共有アカウント禁止、3-2-1 ルール）は、一般に流通している IPA / NISC / NIST の指針の内容と照合したが、WebSearch による一次資料の再確認は行っていない。
- 抽出対象外の B 問題（drill 66 問、alg-core 30 問、alg-applied 32 問）は第 2 次レビューの対象外で、機械検証（実行）のみである。
